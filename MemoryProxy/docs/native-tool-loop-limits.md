# Native 工具循环与取消

默认不再额外限制 Native 循环轮数、每轮调用数和累计调用数。原来的 `round`、`totalCalls` 继续记录，历史位置、执行权和恢复流程不变。

```yaml
nativeProxyTools:
  maxRounds: 0
  maxCallsPerRound: 0
  maxTotalCalls: 0
```

`0` 表示不设置该项上限；显式配置正数时仍执行限制。升级旧实例时，需要将已有配置中的 `5 / 8 / 20` 改为上述值，或删除这三项使用默认值；仅更新代码不会覆盖旧配置。

客户端断开当前 HTTP 请求时，取消信号传入上游请求、Native 工具执行、结果等待和后续模型续写。取消后不启动新的工具执行或重试，不再发起下一次续写；客户端回填恢复使用本次请求的信号，不复用旧信号。正常返回客户端工具后关闭连接，不视为主动取消。

单次工具执行默认 20 秒、结果大小默认 64 KiB、上游已有的单次请求超时、参数及权限检查继续保留。取消不能回滚已经发到后端的操作，超时也不代表操作未执行；已保存的工具结果保留。

如果客户端已经正常收到 Client Tool 批次，当前没有挂起的 HTTP 请求，Proxy 无法感知此后客户端单方面停止。已启动的后台工具仍受单次超时保护；没有新的客户端回填请求，就不会自动发起下一轮续写。

代理不新增整任务计时器。无人值守运行应在客户端设置任务时间或费用预算，并在终止任务时断开请求。评测中 Baseline、Native 使用相同任务超时；代理内部的轮数不等于 Claude Code 的客户端轮数。

本次修改不自动重启实例、不改变运行中的评测，也不修复“后台有数据但查询返回空”的独立问题。切换配置与代码后，应重新建立实验，不能把两种限制下的延迟混在一组结果中。
